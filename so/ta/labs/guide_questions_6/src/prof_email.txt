One thing to note about terminology is that I make a distinction between logical size and capacity. Logical size basically just means how many elements are currently stored in the array, while capacity is the physical size of the array when we declared it. Please be consistent in using the terminology. Also, when I discuss functions, especially those that deal with arrays, I have the tendency to use the const keyword in the formal parameters. The reason behind this one is that I do not want the function to modify the array. That is one design choice that you might notice throughout the course.
